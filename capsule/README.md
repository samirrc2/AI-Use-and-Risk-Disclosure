## Study summary

Industry surveys report that a majority of registered investment advisers (RIAs) now
use artificial intelligence (AI), yet what advisers commit to in their legally binding
fiduciary disclosures has been unmeasured. From the SEC Form ADV Part 1 structured
data (16,223 active SEC-registered advisers reporting regulatory AUM), the study draws
a stratified random sample of 400 firms (adviser type × AUM quartile), retrieves each
firm’s current Form ADV Part 2A brochure from the Investment Adviser Public Disclosure
(IAPD) system, and classifies each brochure with a five-label typology using a large
language model.

**Main findings regenerated by this artifact:**

- **Disclosed AI use is low and steeply stratified:** 23.7% of brochures (95% CI
  19.7–28.2) disclose any use, rising from about 9% among the smallest advisers to
  30% (wealth/retail) and 56% (private-fund) among the largest; trend and adviser-type
  effects are both significant (logistic regression, *p* < 0.001).
- **Survey-weighted estimate** (brochure-filing population): 22.7% (95% CI 18.7–26.6).
- **Dominant disclosure mode** is a risk warning (27.6%), not a claim of use.
- **Independent cross-family validation** (180 blinded brochures; design-weighted):
  any-use κ = 0.74 (precision 0.76, recall 0.84); risk-factor label κ = 0.93.
- **Targeted human verification** (158 cases: 120 brochures, 38 websites; two coders
  blind to the model labels): composite any-use precision 0.76 (95% CI 0.67-0.84),
  sensitivity 0.81, specificity 0.94, with the two-phase verification weights applied.
- **Potential AI-washing exposure** is rare in brochures (5/388, 1.3%; 95% CI 0.6-3.0).
- **Raw prevalence is higher in brochures** (23.0%) than on websites (5.7%) across 283
  matched firms, but the venue indicator is indistinguishable from zero once document
  length is included, and the two length distributions barely overlap. The artifact
  reproduces that conditioning, not only the raw gap.
- **Prevalence is itself a measurement result:** the same corpus yields 9.9%, 13.1% and
  23.7% as the construct, universe and weighting change.

Aligned with Frontiers’ data-availability policy: analysis data needed to reproduce
the reported results are shared openly in this repository and via the Code Ocean
compute capsule (persistent DOI below).

| Item | Location / access |
|------|-------------------|
| Pseudonymized analysis dataset | [`data/`](data/) (committed; see [`data/README.md`](data/README.md)) |
| Measurement instruments (prompts) | [`data/prompts/`](data/prompts/) |
| Design / provenance documentation | [`docs/`](docs/) |
| Code Ocean capsule | https://doi.org/10.24433/CO.3404788.v1 |

**Access conditions:** the released files are keyed by pseudonymous `fid`
(`F0001`…`F0400`). Firm names and CRD numbers are withheld. All published statistics
are invariant to firm identity and reproduce exactly from these files. The private
CRD crosswalk is retained by the authors and available on reasonable request solely
to re-fetch raw brochures; it is **not** required to reproduce any reported result.

**Not redistributed here (with reason):**

- Full SEC Form ADV bulk dump (~4.4 GB; firm-identifiable) — public at source; only
  stratum counts derived from it are shipped (`data/population_strata.csv`).
- Raw brochure / marketing text — firm-identifiable; classification outputs are frozen
  in `data/labels_*.csv` and venue tables.

A Frontiers submission will also generate the journal’s formal **Data Availability
Statement** from the answers entered in the submission form; this README is the
human-readable companion for reviewers and reusers.

## How to reproduce

### Code Ocean

Capsule: https://doi.org/10.24433/CO.3404788.v1

1. Open the compute capsule.
2. Click **Reproducible Run** (`/code/run` → `bash code/scripts/reproduce.sh`).
3. Inspect outputs:
   - `/results/metrics_summary.md` (verdict first), `/results/tables/`, `/results/figures/`
   - `/results/figures/publication/` (Figures 1 and 2 exactly as typeset in the article)
   - `/results/revision/` (robustness, temporal falsification, venue-length conditioning)
   - `/results/replication_check.md` (SHA-256 table hashes; expect **PASS**)

### Local

```bash
git clone https://github.com/samirrc2/AI-Use-and-Risk-Disclosure.git
cd AI-Use-and-Risk-Disclosure
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r code/requirements.txt
bash reproduce.sh                 # analyze + byte-identical check → results/latest/
bash reproduce.sh --analyze-only  # analyze only
bash reproduce.sh --test          # unit tests (no data needed)
```

**Expected headlines** (`results/latest/metrics_summary.md`):

```
Disclosed any-use (design): 23.7% (95% CI 19.7-28.2); n=388
Survey-weighted any-use (brochure-filing): 22.7% (95% CI 18.7-26.6)
Independent cross-family validation (n=180, design-weighted): any-use κ=0.738, precision 0.761, recall 0.837
Targeted human verification (n=120 brochures): any-use precision 0.764, sensitivity 0.807, specificity 0.936
AI-washing exposure screen: 5/388 brochures (1.3%)
Venue comparison (n=283): brochure 23.0% vs marketing 5.7%
```

A successful full run ends with:

```
PASS — all table artifacts byte-identical across runs.
```

That verdict is from a SHA-256 comparison of every table across two independent
runs (`results/latest/replication_check.md` locally;
`/results/latest/replication_check.md` on Code Ocean).

## Use of AI in the research workflow

Per Frontiers’ generative-AI guidelines: large language models were used as
**measurement instruments** to classify brochure / marketing text under frozen
prompts (`data/prompts/`). Model identities, prompts, and validation design are
documented in the manuscript Methods and in [`docs/`](docs/). Authors verified
quantitative outputs by independent re-analysis from the frozen labels. Any
generative-AI assistance in manuscript writing/editing is acknowledged in the
article Acknowledgements / Methods as required by Frontiers.
